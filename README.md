# Econometria II - apresentacao editavel

[**Abrir PDF atualizado (54 slides)**](Apresentacao_Econometria_II.pdf)

Este repositorio contem somente o necessario para editar e recompilar a apresentacao:

- `Apresentacao_Econometria_II.pdf`: versao atual.
- `apresentacao.tex`: fonte LaTeX completo. Inclui os textos, as tabelas e os dados dos graficos vetoriais; nao precisa de imagens externas nem das bases de estimacao.

Para alterar algum detalhe, edite `apresentacao.tex`. Para gerar o PDF, execute `tectonic apresentacao.tex` com Tectonic instalado. O resultado sera `apresentacao.pdf`.

Para baixar os arquivos, use **Code > Download ZIP**. As versoes anteriores permanecem no historico do Git.
